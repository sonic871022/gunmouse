# GunMouse v1.0.1 — 当前推荐版本

发布日期：2026-11-21
状态：已实机验证（枪声触发、侧握横移、开机不漂移均确认可用）

> ⚠️ **请优先用本版本**。`v1.0.0` 存在上电后前几十秒光标漂移的问题，已在本版修复。
> 本版固件与 v1.0.0 的源码差异只有开机零偏处理逻辑，其余功能一致。

## 本版怎么用（一句话）

**枪声开火 = 实时音量超过阈值就触发，阈值自己用按键调；瞄准方向 = 按一次 `L` 让固件学会你怎么拿枪。**

不需要预先录枪声、不需要采集样本、不需要匹配模板。

### 为什么不做"预录枪声对比"

早期试过"录一段枪声当模板、实时声音做相似度匹配"的方案，实测后被否决：
玩具枪的击发声会随**角度、距离、力度、电量、房间反射**大幅变化，一个人录的模板换到
另一个人、另一支枪、另一个房间就失效，反而要反复补录多个样本才能用。

现在改成**纯能量阈值**：只判断"这一下够不够响"，用一个数字阈值就能适配任何枪和任何环境。
官方低麦克风增益（`0x14=0x10` / `0x17=0xBF`）保证枪声与环境音之间有足够的响度差，
不会被一起放大到削波顶格。范围 12800~1024000，每档 ×1.3，边打边调即可。

### 为什么需要"自动学习轴"

每个人绑枪的姿势不同（尤其侧握时，横移会变成"绕枪管倾斜"），固定写死 X/Y/Z 轴映射
必然别扭。`L` 键让你按自己最舒服的动作摆两下，固件自动把陀螺仪轴绑上去，换握法重学一次即可。

## 首次使用（约 5 分钟）

1. **烧录后开机保持设备静止约 13 秒**（4 秒陀螺仪预热 + 1.2 秒校准 + 8 秒鼠标抑制）。
   这段时间是等 BMI270 温度趋稳、零偏收敛，期间光标不动属正常。
2. 按 **`L`** 学习轴：屏幕提示 `SWING LEFT-RIGHT` 时左右摆臂 2 秒，
   再提示 `TILT UP-DOWN` 时上下摆 2 秒，显示 `LEARNED H=? V=?` 即自动保存。
   - 若摆右鼠标往左走，按 `i` 翻水平、`k` 翻俯仰。
3. 按 **`F`** 循环切换射击模式，直到屏幕顶部出现洋红色 **`THR`**
   （顺序 SINGLE → RAPID → THR → SINGLE）。
4. 对着枪扣扳机，看屏幕参数行 `S8.0 THRxxxxx Pxxxxx SH0` 里的 **`P`**（当前实时音量）：
   - 用 **`=`** 调高 / **`-`** 调低 `THR`，把阈值设在**略低于枪声峰值、明显高于说话/环境音**的位置。
   - 超阈值立即开火；一直超阈值就持续连发（约 20 发/秒）；掉回阈值下立刻停火。
   - 调好的值掉电保存，开机校准不会覆盖。
5. 按 `r` 归中，再用 `2/3/4/5` 按自己屏幕实测微调落点；`,` `.` 调灵敏度。
6. 进游戏后**电脑静音或戴耳机**——游戏音效会被麦克风听到造成误触发。

> 说明：开机默认是 SINGLE 模式，且新设备没有任何模板，此时走的也是"音量超阈值"兜底逻辑，
> 所以不切模式也能用。但 **THR 模式显示实时 `P` 值、支持持续连发，调参最直观，推荐切过去**。

## 本版修复了什么

- **上电漂移**：陀螺仪上电后零偏随温度缓慢变化。现改为校准前先预热 4 秒、开机抑制鼠标输出
  8 秒，且抑制期内**强制收敛零偏**（阈值放宽到 15dps、每帧 2%），放开时零偏已到位。
- **持续往右下角偏移（v1.0.0 之后的一次回归）**：曾把静止判据改成"减零偏后的残差"，
  温漂稍大时判据永不满足、零偏被锁死，恒定偏差持续累加成位移。已回退为原始角速度判据 +
  0.3% 慢收敛，并加上面的抑制期兜底。
- 相关时长在源码顶部 `GYRO_WARMUP_MS` / `BOOT_HOLD_MS` 可调（稳定性优先，默认 4000 / 8000）。

## 完整功能

- BMI270 角速度 → USB HID 鼠标移动（滤波 / 死区 / 灵敏度可调）
- ES8311 麦克风 → USB 鼠标左键（纯音量阈值触发，阈值按键实时可调并掉电保存）
- `L` 自动学习轴、`i`/`k` 翻转方向、`y`/`z` 手动切轴
- `r` 归中 + `2/3/4/5` 微调 + `t` 撞墙标定
- `1` 横竖屏切换、`d` 调试显示、`o`/`p` 左右键测试、G0 按钮手动开枪
- SINGLE / RAPID 两套模板匹配算法**代码保留但不推荐**，仅供历史兼容；不录模板即可正常使用

## 编译环境（重要）

- **esp32 core 3.2.1**（IDF 5.4）—— 切勿用 3.3.x，其 legacy I2S 回归会让 ES8311 麦克风
  返回恒定假数据（屏幕 `MIC FLAT!`）
- M5Unified 0.3.0 / M5Cardputer（无需改动）
- FQBN（**`USBMode=default,CDCOnBoot=default` 必带**，否则被识别成串口而不是 HID 鼠标）：
  ```
  esp32:esp32:m5stack_cardputer:FlashSize=8M,PSRAM=disabled,PartitionScheme=default_8MB,USBMode=default,CDCOnBoot=default
  ```
- 不使用 PSRAM（ADV 无 PSRAM）

## 烧录

整片镜像（8MB，含 bootloader + 分区表 + app，从 `0x0` 刷，最省事）：
```
python -m esptool --port COM3 --chip esp32s3 write_flash 0x0 gunmouse-v1.0.1-merged.bin
```

或只刷应用分区（需已有正确的 bootloader/分区表）：
```
python -m esptool --port COM3 --chip esp32s3 write_flash 0x10000 gunmouse-v1.0.1.bin
```

烧录后 COM3 消失属正常（设备变成 HID 鼠标）。再次烧录需进下载模式：
电源 OFF → 按住 G0 → 拨回 ON → 松开。

## 已知事项

- 开机约 13 秒后才完全可用，这是为消除温漂刻意设置的等待，不是故障。
- 每次整片刷入其它固件（例如原厂 CarHUD）会覆盖 NVS，枪声阈值 / 学轴结果 / 归中微调会丢失，
  需重新用 `-` `=`、 `L`、`2/3/4/5` 调一遍。
- 麦克风增益在源码顶部 `MIC_PGA_GAIN` / `MIC_ADC_VOL` 可微调：枪声 `P` 太小触发不了就调高，
  环境音太容易误触就调低。
- Windows「提高指针精确度」（鼠标加速）会让位移→像素非线性，追求跟手可关闭后重新归中。

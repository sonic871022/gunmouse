# GunMouse —— Cardputer ADV 光枪鼠标

> **当前稳定版：v1.0.0（2026-11-21）** — 已实机验证可用。
> 发布快照在 [`releases/v1.0.0/`](releases/v1.0.0/)：含源码 `.ino`、应用固件、8MB 整片镜像、
> 校验清单 `SHA256SUMS.txt` 和 [版本说明](releases/v1.0.0/RELEASE_NOTES.md)。
> 提交到 git 前请先读文末「开源/提交前整理」；本项目尚未初始化 git。

把 Cardputer ADV 绑在电动玩具枪上，变身 PC 射击游戏的光枪控制器：

- **BMI270 陀螺仪**角速度 → USB 鼠标移动（游戏内瞄准）
- **内置麦克风**检测枪击声 → USB 鼠标左键（游戏内射击）
- **屏幕**实时显示准星、音量包络、阈值、参数
- 所有参数**按键实时可调 + 掉电保存**（NVS）

```
Cardputer ADV（绑在枪上）
 ├─ 陀螺仪角速度 ──滤波/死区/灵敏度──→ USB 鼠标移动
 ├─ 麦克风枪声  ──边沿检测/阈值──────→ USB 鼠标左键
 └─ USB-C 数据线（建议有线，FPS 延迟低于蓝牙）
```

## 烧录

沿用本机已验证的烧录链路（设备插 USB-C，通常 COM3）。
**关键：FQBN 必须显式指定 `USBMode=default,CDCOnBoot=default`，否则板子默认是硬件
CDC 串口模式（VID_303A&PID_1001），电脑会把设备识别成串口而不是鼠标，HID 完全失效！**

```
"C:\Program Files\Arduino CLI\arduino-cli" upload -p COM3 ^
  --fqbn "esp32:esp32:m5stack_cardputer:FlashSize=8M,PSRAM=disabled,PartitionScheme=default_8MB,USBMode=default,CDCOnBoot=default" ^
  --input-dir E:\M5stack\gunmouse\build321
```

重新编译（同样必须带 USB 选项）：

```
"C:\Program Files\Arduino CLI\arduino-cli" compile ^
  --fqbn "esp32:esp32:m5stack_cardputer:FlashSize=8M,PSRAM=disabled,PartitionScheme=default_8MB,USBMode=default,CDCOnBoot=default" ^
  --build-path E:\M5stack\gunmouse\build321 E:\M5stack\gunmouse
```

### ⚠️ 烧录后 COM3 会消失——这是正常现象

本固件使用 **USB-OTG(TinyUSB) HID** 模式（CDC 关闭），设备对电脑就是一只鼠标，
USB-Serial/JTAG 的串口不复存在。

**再次烧录的方法**（进入下载模式）：
1. 侧面电源开关拨到 OFF
2. **按住 G0**（背面银色按钮）
3. 保持按住的同时把电源开关拨回 ON（或按一下 RST 再松开 G0）
4. COM 口重新出现，即可正常 upload

## 使用流程

1. 开机后自动进入**校准**（1.2 秒）：把枪放在桌上保持静止、别出声
   - 测陀螺仪零偏 + 环境噪声底，自动算出枪声触发阈值
2. 插到电脑上，设备被识别为鼠标
3. 先在**桌面**上测试：转枪 → 光标移动；扣扳机"哒"一声 → 左键点击
4. 没问题就进游戏（CS / Valorant / Aim Lab……），游戏里**把音量静音**
5. 瞄准不跟手就调参（见下）

## 按键说明

| 键 | 功能 |
|---|---|
| `,` / `.` | 灵敏度 − / +（每度转角对应的鼠标计数） |
| `-` / `=` | **枪声触发阈值 − / +**（任何模式都生效，×1.3 每档；调过的值掉电保存、开机不再被校准覆盖） |
| `[` / `]` | 有模板且非 THR 模式：匹配度阈值 − / +（默认 85%）；否则等价于 `-` / `=` 调触发阈值 |
| `g` | **追加枪声模板**：录 1 秒，期间开一枪，存为一个样本（最多 8 个） |
| `h` | **清空模板列表**（切回无模板的能量阈值模式） |
| `l` | **自动学习轴**：按提示左右摆臂 2 秒 + 上下摆 2 秒，固件自动把横移/俯仰绑到对应的陀螺仪轴并保存。换握法/绑法后重学一次即可（解决侧握时横移别扭） |
| `y` / `z` | 切换水平 / 俯仰使用的陀螺仪轴（X/Y/Z）。**z 是俯仰轴键** |
| `i` / `k` | 反转水平 / 俯仰方向（学习后若摆右鼠标往左走，按 `i` 翻水平、`k` 翻俯仰） |
| `o` / `p` | 鼠标左键 / 右键点击测试（验证 HID 通断） |
| `r` | **归中**：把电脑光标移到屏幕正中央 |
| `2` / `3` | 归中 X 位移 − / +（每次 10 count，实时生效、松开自动存盘） |
| `4` / `5` | 归中 Y 位移 − / +（每次 10 count） |
| `t` | 归中标定（撞墙归零→按住 o 推到水平中心按 t→按住 p 推到垂直中心按 t） |
| `1` | 旋转屏幕方向（横屏两方向切换，掉电保存） |
| `f` | 循环切换射击模式：**SINGLE 单发 → RAPID 连发 → THR 粗暴阈值**（三套独立算法，见下） |
| `c` | 重新校准（陀螺仪零偏 + 噪声底 + 阈值；会清掉手动阈值标记，恢复自动阈值） |
| `d` | 开关调试信息（实时显示陀螺仪原始值/零偏/峰值） |
| **G0 按钮** | 手动开一枪（不用枪也能测鼠标点击） |

> 键码说明：Cardputer 用的是键盘扫描码，`z`=0x1D、`y`=0x1C、数字 `1`=0x1E。
> 早期版本误把俯仰轴键标成 `u`，实际物理 `Z` 键才触发俯仰轴切换，本版已改正并保留该功能。

## 屏幕读法

```
GUN-MOUSE  SINGLE  ARMED          ← 状态：ARMED=待击发 / FIRE!=射击中 / -----=恢复期
S8.0 C85% T3/8 -Z/-X SH12         ← 灵敏度/匹配度阈值/模板数/轴与方向/射弹数
CTR X674 Y382  m92%#2             ← 归中位移 + 实时匹配度/命中模板号
        + 准星（开枪时变红）
S8.0 THR4000 P1200 SH3            ← THR 模式：触发阈值 T / 当前实时音量 P
[███████│          ]  400        ← 麦克风包络条，黄线=触发阈值，数字=当前包络
```

## 枪声识别（多模板）

开机后按 `g` 会进入 1 秒录音界面，提示 `FIRE ONE SHOT NOW` —— 这时**对着麦克风开一枪**，
固件自动截取枪声能量包络存为一个模板。屏幕 `T3/8` 表示已存 3 个模板（最多 8 个）。

**为什么要录多个**：电动枪的击发声会随角度、距离、力度、电量变化。录一个模板容易漏判，
把同一支枪在**不同距离/角度/力度**下多开几枪、各录一个样本（`g` 是追加不是覆盖，
按住 `g` 会依次存到 slot 1、2、3…），识别率会明显提高。射击时任意一个模板匹配度达标就开火，
屏幕 `m92%#2` 显示实时匹配度和最近命中的模板号。

**阈值调节**：`[` `]` 调匹配度阈值（默认 85%，范围 50~95%）。
- 误触发（微小声音/说话也开火）→ 按 `]` 提高阈值
- 漏判（开枪没反应）→ 按 `[` 降低阈值，或补录几个该场景的模板
- 想全部重录 → 按 `h` 清空列表

> ADV 绑在墙上离枪声极近、信号很强，所以本版**故意把门槛调高**（能量门限 0.35、
> 匹配度 85%）来屏蔽房间环境音/说话声。贴近的枪声远超门槛，不会漏判。

**单发 / 连发（按 `f` 切换，两套独立算法）**：
- **SINGLE（单发）**：命中后立刻清空采样窗口 + 强制锁定 180ms + 必须等能量回落到谷底
  才解锁。一发枪声只打一次，**彻底杜绝"停下来后又补触发一次"**。适合点射。
- **RAPID（连发）**：命中后只等能量回落到谷底就解锁、不清窗口，最短间隔 50ms
  （约 20 发/秒）。跟进射速，适合扣住扳机连发。

切换模式时会重置检测状态，可随时按 `f` 切换而不留残留。

### ★ THR 粗暴阈值模式（推荐先试这个）

按 `f` 切到 **THR**（屏幕顶部洋红色 `THR`）。这是最简单直接的方案，**不看模板、不算相关系数**：

- 实时音量（瞬时峰值）**> 阈值 `T` → 立即开火**；
- 只要**一直超过阈值 → 持续连发**（按住左键 45ms、松开、再按，循环，约 20 发/秒）；
- 音量掉回阈值以下 → 立刻停火。

屏幕参数行 `S8.0 THR4000 P1200 SH3`：`THR` 后是触发阈值，`P` 后是**当前实时音量**。
边扣扳机边看 `P` 数字：枪声能冲到多少，就把阈值 `T` 调到略低于它。

**调阈值**：`-` 降 / `=` 升（或 `[` `]`），每档 ×1.3，范围 **12800~1024000**。
- 调高：需要更大的声音才开火，环境音/说话不再误触；调低：远一点的枪声也能触发。
- **调过的值会掉电保存，开机校准不再覆盖**（旧版每次开机把调好的阈值重置成自动值的 bug 已修）。
- 想恢复自动校准：按 `c` 重新校准。

> **阈值为什么能到 100 万**：音频是 16 位采样，原始峰值物理上限 32767，若阈值卡在 32000 就再也调不高、也几乎没有调节余地。本版把「音量与阈值」的量纲统一放大了 **32 倍**（显示的数字也同步放大），所以阈值上限提到约 100 万、调节粒度更细。你之前调好的阈值会在首次开机时**自动等比迁移**，触发门限不变，无需重调。
>
> ⚠️ **削波问题已修**：旧版误用超高麦克风增益（PGA +21dB + ADC +6dB），贴脸枪声和环境音一起削波顶到 32767，阈值怎么调都区分不开。现改回 Cardputer ADV 官方低增益（`0x14=0x10` PGA 最小 / `0x17=0xBF` ADC 0dB），恢复真实动态范围。增益变更后旧阈值会作废、开机自动重新校准。源码顶部 `MIC_PGA_GAIN` / `MIC_ADC_VOL` 可微调（每档约 +3dB / +0.5dB）：若枪声 `P` 值太小触发不了就调高，若环境音太容易触发就调低。

**注意**：本版改了模板存储结构（峰值锚定位置 + 裁切方式），旧模板不兼容，
烧录后需按 `g` 重新录一遍。录音时固件会先估环境噪声底，自动跳过按键等前导微弱波动，
从枪声真正的起振点截取包络，识别更准。

模板存在 NVS 里，断电不丢。NVS 版本更新后会自动用新阈值默认值覆盖旧设置。

## 调参指南

**轴映射**（第一次绑定好后必做）：
按 `d` 开调试，慢慢左右转枪，看哪个轴（g 后面三个数）变化最大 → 那就是"水平"轴（`y` 键切到它）；再抬头低头找"俯仰"轴（`z` 键）。方向反了按 `i` / `k`。
最终调好的值：`S38.1 T400 +X/-Z`（灵敏度 38.1、水平轴 X 不反转、俯仰轴 Z 反转）。

**灵敏度**：桌面测试时，一次自然甩枪能横移半屏左右比较合适，`,` `.` 微调。

**归中位置（R 键）**——这是本次新增的可调变量：
Windows 开着"提高指针精确度"（鼠标加速），归中推送量会被放大约 1.89 倍，因此需要按你的屏幕实测微调。有两种改法：

- **设备上直接调（推荐，免烧录）**：把光标移到角落 → 按 `r` 归中 → 看落点偏哪：
  - 偏右 → 按 `3` 增大 X；偏左 → 按 `2` 减小 X（每次 10）
  - 偏下 → 按 `5` 增大 Y；偏上 → 按 `4` 减小 Y（每次 10）
  - 屏幕 `CTR X.. Y..` 行实时显示数值，松开约 0.6 秒后自动存盘，掉电不丢。
- **改源码常量**：文件顶部 `CENTER_X` / `CENTER_Y` 两个数字就是归中值，改完把 `CENTER_CFG_VER` 加 1 再编译烧录，会强制覆盖设备旧值。

> 当前基准值 `CENTER_X=674 / CENTER_Y=382` 是根据你 2560×1440 屏幕 + 1.89x 加速反推的
> （标定值 928/528 落到屏幕 1762,995，反推到中心 1280,720 所需的值）。若按 R 仍偏，用上面的键微调即可。

**阈值**（推荐用 THR 模式，见上节）：对着枪扣扳机，看屏幕 `P` 数字和包络条：枪声应明显冲过黄线阈值（平时说话/走动不能过）。冲不过就 `-` 降低阈值；误触发就 `=` 提高。调好的值掉电保存、开机不再被覆盖；换环境后按 `c` 重新校准（恢复自动阈值）。

## 已知坑与注意

1. **esp32 core 3.3.x 麦克风 bug（已解决）**：core 3.3.x 内置 ESP-IDF 5.5.2 有上游回归
   （espressif/esp-idf#18621），ES8311 麦克风返回恒定假数据（屏幕 `MIC FLAT!` / pk 恒定）。
   **本固件必须用 esp32 core 3.2.1（IDF 5.4）编译**，本机已安装并设为默认：
   ```
   arduino-cli core install esp32:esp32@3.2.1
   ```
   若误用 3.3.x 重新编译，麦克风会再次失效。（M5Unified/M5Cardputer 库无需变动）
2. **麦克风与扬声器不冲突**：ADV 的 speaker 用 I2S_NUM_1、mic 用 I2S_NUM_0，可共存；
   本固件不调用 `Speaker.end()`（它会写 ES8311 断电序列导致 mic 全 0）。
3. **游戏声音必须静音**：电脑任何枪声音效都会被麦克风听到造成误触发。戴耳机或静音。
4. **建议 USB 有线**：BLE 鼠标有连接间隔抖动，FPS 手感差；有线最稳。
5. 固件不使用 PSRAM（ADV 无 PSRAM），编译选项已按实际硬件设置。
6. 麦克风上电约 1 秒预热，固件已处理（校准前等待）。

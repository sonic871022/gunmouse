# GunMouse —— Cardputer ADV 光枪鼠标

> **当前稳定版：v1.0.1（2026-11-21）** — 已实机验证、已开源：
> **https://github.com/sonic871022/gunmouse**
> 发布快照在 [`releases/v1.0.1/`](releases/v1.0.1/)：源码 `.ino`、应用固件、8MB 整片镜像、
> 校验清单和 [版本说明](releases/v1.0.1/RELEASE_NOTES.md)。
>
> ⚠️ **不要刷 `releases/v1.0.0/` 的固件**：那一版有上电后前几十秒光标漂移的问题，v1.0.1 已修复。

把 Cardputer ADV 绑在电动玩具枪上，变身 PC 射击游戏的光枪控制器：

- **BMI270 陀螺仪**角速度 → USB HID 鼠标移动（游戏内瞄准）
- **内置麦克风** → 纯音量阈值判定枪声 → USB 鼠标左键（游戏内射击）
- **`L` 自动学习轴**：按你的实际握法自动绑定横移/俯仰轴，侧握、倒着绑都不别扭
- **屏幕**实时显示准星、音量、阈值、参数；所有参数**按键实时可调 + 掉电保存**（NVS）

```
Cardputer ADV（绑在枪上）
 ├─ 陀螺仪角速度 ──滤波/死区/灵敏度──→ USB 鼠标移动
 ├─ 麦克风枪声  ──音量 > 阈值──────→ USB 鼠标左键
 └─ USB-C 数据线（建议有线，FPS 延迟低于蓝牙）
```

## 快速开始（新用户）

1. **烧录**固件（见下节），开机后**保持设备静止约 13 秒**
   （4 秒陀螺仪预热 + 1.2 秒校准 + 8 秒鼠标抑制，等温漂收敛，期间光标不动属正常）
2. 按 **`L`** 学轴：屏幕提示 `SWING LEFT-RIGHT` 时左右摆臂 2 秒，
   再提示 `TILT UP-DOWN` 时上下摆 2 秒，显示 `LEARNED H=? V=?` 即自动保存
   - 方向反了：按 `i` 翻水平、`k` 翻俯仰
3. 按 **`F`** 循环切换，直到屏幕顶部出现洋红色 **`THR`**
4. 扣扳机看屏幕 **`P`**（当前实时音量），用 **`=`** / **`-`** 把 `THR` 阈值调到
   **略低于枪声峰值、明显高于说话/环境音**的位置
5. `r` 归中 + `2/3/4/5` 微调落点，`,` `.` 调灵敏度
6. 进游戏后**电脑静音或戴耳机**（游戏音效会被麦克风听到造成误触发）

> 开机默认是 SINGLE 模式，新设备没有任何模板，此时走的也是"音量超阈值"兜底逻辑，
> 不切模式也能用；但 THR 模式显示实时 `P` 值、支持持续连发，调参最直观，推荐切过去。

## 枪声触发：纯音量阈值（本项目的主方案）

**不需要预先录枪声、不需要采集样本、不需要模板匹配。** 只判断"这一下够不够响"：

- 实时音量 **> 阈值 `THR` → 立即开火**
- **一直超阈值 → 持续连发**（约 20 发/秒），掉回阈值下立刻停火
- 阈值 `-` 降 / `=` 升（或 `[` `]`），每档 ×1.3，范围 **12800~1024000**，掉电保存

**为什么否决了"预录枪声模板对比"**：玩具枪的击发声随角度、距离、力度、电量、房间反射
大幅变化，一个人录的模板换到另一支枪/另一个房间就失效，得反复补录多个样本。
纯能量阈值用一个数字就能适配任何枪和任何环境，别人拿到手只需扣几枪看 `P` 值调一下阈值。

**为什么音量能区分得开**：ES8311 使用 Cardputer ADV 官方低增益（`0x14=0x10` PGA 最小 /
`0x17=0xBF` ADC 0dB）。早期误抄成高增益（PGA +21dB + ADC +6dB）会让贴脸枪声和环境音
**一起削波顶到 32767**，响度信息全丢，阈值怎么调都没用。源码顶部 `MIC_PGA_GAIN` /
`MIC_ADC_VOL` 可微调：枪声 `P` 太小触发不了就调高，环境音太容易误触就调低。

> **阈值为什么能到 100 万**：音频是 16 位采样，原始峰值物理上限 32767，阈值若卡在 32000
> 就没有调节余地。本版把「音量与阈值」的量纲统一放大 **32 倍**（显示数字同步放大），
> 上限约 100 万、粒度更细。旧阈值会在首次开机自动等比迁移，触发门限不变。

**开机校准不再覆盖手动阈值**：早期版本每次上电都用自动值把调好的阈值重置掉，
现已修复；想恢复自动阈值按 `c` 重新校准。自动阈值下限为噪声底×6（放大后 96000），
平时说话/环境音一般够不到。

## 自动学习轴（`L` 键）

陀螺仪测的是"绕轴旋转的角速度"，设备绑法/握法一变，原本对应"水平摆臂"的轴就会变成
"绕枪管倾斜"，横移手感立刻变扭。`L` 键不猜姿态，直接按你的动作定轴：

1. 按 `L` → 屏幕 `SWING LEFT-RIGHT`，**用你觉得最像横移的方式**左右摆臂约 2 秒
2. → `TILT UP-DOWN`，上下摆约 2 秒（屏幕有实时三轴活动条）
3. → `LEARNED H=? V=?`，自动保存到 NVS，掉电不丢

换握法、换绑法重新学一次即可。学习只定"哪个轴"，方向反了用 `i`/`k` 翻转；
也可用 `y`/`z` 手动循环切换水平/俯仰轴。

## 按键说明

| 键 | 功能 |
|---|---|
| `l` | **自动学习轴**（左右摆 2 秒 + 上下摆 2 秒，自动绑定并保存） |
| `f` | 循环切换射击模式：SINGLE → RAPID → **THR（推荐）** → SINGLE |
| `-` / `=` | **枪声触发阈值 − / +**（任何模式生效，×1.3 每档，掉电保存） |
| `[` / `]` | 非 THR 且有模板时调匹配度阈值；否则等价于 `-` / `=` |
| `,` / `.` | 灵敏度 − / +（每度转角对应的鼠标计数） |
| `i` / `k` | 反转水平 / 俯仰方向 |
| `y` / `z` | 手动切换水平 / 俯仰陀螺仪轴（X/Y/Z，**z 是俯仰轴键**） |
| `o` / `p` | 鼠标左键 / 右键点击测试（验证 HID 通断） |
| `r` | **归中**：把电脑光标移到屏幕正中央 |
| `2` / `3` | 归中 X 位移 − / +（每次 10 count，松开自动存盘） |
| `4` / `5` | 归中 Y 位移 − / + |
| `t` | 归中标定（撞墙归零→按住 o 推到水平中心按 t→按住 p 推到垂直中心按 t） |
| `1` | 旋转屏幕方向（横屏两方向切换，掉电保存） |
| `c` | 重新校准（陀螺仪零偏 + 噪声底 + 阈值，会恢复自动阈值） |
| `d` | 开关调试信息（陀螺仪原始值/零偏/峰值） |
| `g` / `h` | 追加 / 清空枪声模板 —— **历史方案，不推荐使用**，见文末 |
| **G0 按钮** | 手动开一枪（不用枪也能测鼠标点击） |

> 键码说明：Cardputer 用键盘扫描码，`z`=0x1D、`y`=0x1C、数字 `1`=0x1E。
> 早期版本误把俯仰轴键标成 `u`，实际物理 `Z` 键才触发俯仰轴切换。

## 屏幕读法

```
GUN-MOUSE  THR     ARMED          ← 状态：ARMED=待击发 / FIRE!=射击中 / -----=恢复期
S8.0 THR96000 P184320 SH3        ← THR 模式：触发阈值 / 当前实时音量 / 射弹数
CTR X934 Y532                   ← 归中位移
        + 准星（开枪时变红）
[███████│          ]  184320     ← 音量包络条，黄线=触发阈值，数字=当前音量
```

非 THR 模式参数行显示 `S8.0 C85% T3/8 -Z/-X SH12`（灵敏度/匹配度阈值/模板数/轴与方向/射弹数）。
`C85%`、`T3/8`、`m92%#2` 都属于已弃用的模板方案，不使用模板时无需关心。

## 烧录

**关键：FQBN 必须显式指定 `USBMode=default,CDCOnBoot=default`**，否则板子默认是硬件
CDC 串口模式（VID_303A&PID_1001），电脑会识别成串口而不是鼠标，HID 完全失效。

最省事的方式是整片镜像（8MB，含 bootloader + 分区表 + app）：

```
python -m esptool --port COM3 --chip esp32s3 write_flash 0x0 releases\v1.0.1\gunmouse-v1.0.1-merged.bin
```

用 arduino-cli（设备插 USB-C，通常 COM3）：

```
arduino-cli upload -p COM3 ^
  --fqbn "esp32:esp32:m5stack_cardputer:FlashSize=8M,PSRAM=disabled,PartitionScheme=default_8MB,USBMode=default,CDCOnBoot=default" ^
  --input-dir E:\M5stack\gunmouse\build321
```

重新编译（同样必须带 USB 选项）：

```
arduino-cli compile ^
  --fqbn "esp32:esp32:m5stack_cardputer:FlashSize=8M,PSRAM=disabled,PartitionScheme=default_8MB,USBMode=default,CDCOnBoot=default" ^
  --build-path E:\M5stack\gunmouse\build321 E:\M5stack\gunmouse
```

### ⚠️ 烧录后 COM3 会消失——正常现象

本固件使用 **USB-OTG(TinyUSB) HID** 模式（CDC 关闭），设备对电脑就是一只鼠标。
再次烧录需进下载模式：

1. 侧面电源开关拨到 OFF
2. **按住 G0**（背面银色按钮）
3. 保持按住把电源开关拨回 ON（或按一下 RST 再松开 G0）
4. COM 口重新出现即可 upload

## 调参指南

**灵敏度**：桌面测试时一次自然甩枪能横移半屏左右比较合适，`,` `.` 微调。

**归中（R 键）**：Windows 的"提高指针精确度"（鼠标加速）会让位移→像素非线性，
归中推送量需按你的屏幕实测微调：

- **设备上直接调（推荐）**：把光标移到角落 → 按 `r` 归中 → 看落点偏哪：
  偏右按 `3` 增大 X、偏左按 `2` 减小 X；偏下按 `5` 增大 Y、偏上按 `4` 减小 Y（每次 10）。
  屏幕 `CTR X.. Y..` 实时显示，松开约 0.6 秒自动存盘。
- **改源码常量**：文件顶部 `CENTER_X` / `CENTER_Y`（当前 **934 / 532**），改完把
  `CENTER_CFG_VER` 加 1 再编译烧录，会强制覆盖设备旧值。

**轴映射**：优先用 `L` 自动学习；需要手动时用 `d` 开调试慢慢转枪，看哪个轴变化最大，
用 `y`/`z` 切过去，`i`/`k` 翻方向。

**阈值**：推荐 THR 模式，对着枪扣扳机看 `P` 值和包络条，把黄线调到枪声与环境音之间。
调好的值掉电保存、开机不再被覆盖；换环境后按 `c` 重新校准。

## 已知坑与注意

1. **esp32 core 3.3.x 麦克风 bug（已解决）**：core 3.3.x 内置 ESP-IDF 5.5.2 有上游回归
   （espressif/esp-idf#18621），ES8311 麦克风返回恒定假数据（屏幕 `MIC FLAT!` / pk 恒定）。
   **必须用 core 3.2.1（IDF 5.4）编译**：`arduino-cli core install esp32:esp32@3.2.1`。
   若误用 3.3.x 重新编译，麦克风会再次失效（M5Unified/M5Cardputer 库无需变动）。
2. **麦克风与扬声器不冲突**：ADV 的 speaker 用 I2S_NUM_1、mic 用 I2S_NUM_0，可共存；
   本固件不调用 `Speaker.end()`（它会写 ES8311 断电序列导致 mic 全 0）。
3. **游戏声音必须静音**：电脑任何枪声音效都会被麦克风听到造成误触发。戴耳机或静音。
4. **建议 USB 有线**：BLE 鼠标有连接间隔抖动，FPS 手感差；有线最稳。
5. 固件不使用 PSRAM（ADV 无 PSRAM），编译选项已按实际硬件设置。
6. **开机约 13 秒才可用（稳定性优先）**：麦克风预热 1.1 秒 + 陀螺仪预热 4 秒 +
   校准 1.2 秒 + 鼠标抑制 8 秒。陀螺仪上电有温漂，充分预热后再测零偏，抑制期内额外
   **强制收敛零偏**（阈值 15dps、每帧 2%），避免冷机温漂让判据卡死、零偏锁死造成持续偏移。
   静止判据用原始角速度（曾误用「减零偏后的残差」，实测会导致鼠标一直往右下角飘，已回退）。
   时长在源码顶部 `GYRO_WARMUP_MS` / `BOOT_HOLD_MS` 可调。

## 历史方案：多模板枪声匹配（已否决，代码保留）

早期版本按 `g` 录 1 秒枪声能量包络作为模板（最多 8 个），实时算 Pearson 相关，
按 `f` 在 SINGLE / RAPID 两套算法间切换，`[` `]` 调匹配度阈值，按 `h` 清空模板。

**实测后否决**：泛化差（换枪/换角度/换房间就失效）、需要反复补录样本，
不如直接调一个音量阈值直观。代码保留仅为兼容旧数据，**新用户完全不需要录模板**，
`g` / `h` / `C85%` / `T3/8` 这些显示都可以忽略。模板存 NVS（`TPL_BLOB_VER=3`），
旧模板不兼容时需重录。
